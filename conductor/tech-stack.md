# Pila Tecnológica: Synapse Control Plane

## Infraestructura (Entorno Celular)
- **Sistema Operativo:** Fedora Workstation (Optimizado para drivers de GPU y kernel actualizado).
- **Gestión de Contenedores:** Podman (Enfoque rootless para seguridad inmunológica).
- **Orquestación Local:** Kind / Podman Desktop para simulación de microservicios.

## Inteligencia y Lógica (El Cerebro)
- **Lenguaje Principal:** Python 3.12+ (Estándar de oro para IA y backend).
- **Orquestador de Estados:** LangGraph (Grafos cíclicos para flujos de feedback y máquinas de estados).
- **Validación de Datos:** Pydantic (Gobernanza de tipos y formatos para sectores regulados).
- **API Framework:** FastAPI + Uvicorn (Comunicación asíncrona y ultrarrápida).

## Memoria y Pizarra (El Hipocampo)
- **Pizarra en Tiempo Real:** Redis (Memoria de trabajo de baja latencia para colaboración multiagente).
- **Base de Datos Vectorial (RAG):** Qdrant o ChromaDB (Memoria de largo plazo y consulta de evidencia).
- **Persistencia de Datos:** PostgreSQL (Almacenamiento relacional robusto con encriptación en reposo).

## Modelos y Gobernanza (Neurotransmisores)
- **Inferencia Local:** Ollama (Ejecución de Llama 3 / Phi-3 para soberanía de datos).
- **Orquestador Global:** Gemini 1.5 Flash (Ventana de contexto masiva para supervisión de alto nivel).
- **Agente Guardián:** Small Language Models (SLM) especializados en cumplimiento normativo y ética.

## Interfaz (Sistema Sensoriomotor)
- **Frontend:** React + Tailwind CSS (Panel de control minimalista).
- **Visualización:** Tremor / Recharts (Gráficos de red dinámicos y métricas de eficiencia/ROAI).

## Bibliotecas y Herramientas Adicionales
- **Testing:** pytest, pytest-asyncio, pytest-cov, httpx.
- **Configuración:** pydantic-settings (Gestión de variables de entorno).
- **Integración LLM:** ollama (Cliente Python oficial), langchain-core (Estructuras base).
